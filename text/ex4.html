Ce que les participants ont appris

Le moment préféré du groupe ? Comprendre qu'une balise ouverte doit toujours être fermée. Voici les balises les plus utilisées pendant l'atelier :

  • <h1> à <h6> pour les titres ;
  • <p> pour les paragraphes ;
  • <ul>, <ol> et <li> pour les listes ;
  • <a> pour les liens et <img> pour les images.
